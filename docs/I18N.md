# Languages (i18n)

storageCleaner ships in **English** and **Georgian (ქართული)**. Switch in
**Settings → Language** or with the **EN | ქა** pill in the top bar. The choice
is saved on the PC (`localStorage: storageCleaner.lang`).

## Where the text lives

| File | What |
|---|---|
| `app/src/i18n/en.ts` | Source of truth: every UI string, flat dotted keys |
| `app/src/i18n/ka.ts` | Georgian. Typed `Record<keyof typeof en, string>`, so a missing key is a **compile error** |
| `app/src/i18n/backend.ts` | Translations for text produced by the Rust core (safety reasons by rule id, categories, plan titles, recommendation reasons, delete warnings/errors) via ids and patterns. Unknown text falls back to English |
| `app/src/i18n/index.ts` | `t(key, params)`, `tn(key, n)` (plural), `LANGUAGES`, locale |
| `app/src/i18n/useT.ts` | `useT()` hook: components re-render on switch |

Usage: `const { t } = useT(); t("hist.deleted", { n: 6 })` fills `{n}`.

## Adding a language

1. Copy `ka.ts` to `xx.ts` and translate every value (TypeScript tells you what's missing).
2. Add it to `DICTS` and `LANGUAGES` in `i18n/index.ts` (with a short label and locale).
3. Add its backend translations in `backend.ts`.
4. If WebView2 lacks the locale's date data (as with Georgian), add a manual formatter in `lib/format.ts` like `kaDate()`.

## Rules

- Keep **storageCleaner**, size units (B/KB/MB/GB) and paths in Latin.
- The permanent-delete phrase **DELETE PERMANENTLY** is never translated: the Rust core checks it exactly.
