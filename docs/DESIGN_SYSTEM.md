# storageCleaner Design System

All colours and sizes live in **one file**:
[`app/src/index.css`](../app/src/index.css). Components never hard-code
colours, so you can restyle the app or add themes without touching them.

## Two layers

```
Theme tokens (--sc-*)            Tailwind tokens (@theme)          Components
per theme, switched at runtime → stable names used in classes → bg-surface, text-muted,
[data-theme="ember"] { … }       --color-surface: var(--sc-…)      rounded-card, indigo-500…
```

1. **Theme tokens: `--sc-*`** (bottom of `index.css`). The raw values of a
   theme. Every theme defines the same set. The active theme is chosen with
   `<html data-theme="…">`.
2. **Tailwind tokens: `@theme`** (top of `index.css`). The names components
   use. They only reference theme tokens.

## Tokens

### Colours

| Tailwind class | Theme token | Use |
|---|---|---|
| `bg-bg` | `--sc-bg` | App background (with `--sc-glow-1/2` ambient glows) |
| `bg-surface` | `--sc-surface` | Panels |
| `bg-surface-raised` | `--sc-surface-raised` | Raised areas, tracks |
| `bg-overlay` | `--sc-overlay` | Tooltips, toasts, floating trays |
| `border-line` | `--sc-border` | Dividers |
| `text-fg` / `text-muted` | `--sc-text` / `--sc-text-muted` | Text |
| `*-indigo-50…950`, `bg-accent` | `--sc-accent-*` | **Accent** (Ember: orange) |
| `*-cyan-50…950`, `bg-mint` | `--sc-positive-*` | **Positive / highlight** (Ember: mint) |
| `*-slate-50…950` | `--sc-neutral-*` | Neutral greys |

The `indigo` / `cyan` / `slate` names are historic: they're **remapped** to
the theme's accent / positive / neutral scales, so `bg-indigo-500` is always
"the accent". Prefer the semantic names in new code.

Safety colours (green Safe, amber Review, red Protected) stay the same in
every theme on purpose, so they always mean the same thing
(`app/src/lib/format.ts → SAFETY`).

### Sizes

| Class | Token | Value | Use |
|---|---|---|---|
| `rounded-card` | `--radius-card` | 22px | Cards, stat tiles, banners |
| `rounded-panel` | `--radius-panel` | 24px | Rail, modals |
| `rounded-control` | `--radius-control` | 14px | Rail buttons, inputs |
| `rounded-full` | | | Buttons, pills, chips |

### Surfaces & controls (`index.css`)

| Class | What |
|---|---|
| `.glass` | Glassy gradient surface with a subtle border and depth shadow |
| `.btn-primary` | Accent gradient button with a glow (`<Button variant="primary">`) |

### Charts

ECharts draws on a canvas, so it can't read CSS variables directly. Use the
hook, which resolves the tokens and recomputes when the theme changes:

```tsx
const { SERIES_COLORS, CHART_TEXT, CHART_LINE, tooltipBase, theme } = useChartTheme();
const option = useMemo(() => ({ color: SERIES_COLORS, tooltip: { ...tooltipBase } }), [data, theme]);
```

Tokens: `--sc-chart-1…8`, `--sc-chart-text`, `--sc-chart-grid`,
`--sc-tooltip-bg`, `--sc-tooltip-text`.

## Adding a theme

1. In `index.css`, copy an existing `[data-theme="…"]` block, rename it
   (e.g. `[data-theme="ocean"]`) and change the values. Define **every**
   `--sc-*` variable.
2. Register it in [`app/src/lib/theme.ts`](../app/src/lib/theme.ts)
   (`THEMES`: id, name, description, 4 preview swatches).

It then shows up in **Settings → Appearance**. The choice is saved in
`localStorage` and applied before the first paint (`main.tsx`).

## Built-in themes

| Theme | Feel |
|---|---|
| **Ember** (default) | Warm near-black, orange accent, mint highlights |
| **Midnight** | Cool navy, indigo accent, cyan highlights |
| **Forest** | Green-black, emerald accent, amber highlights |

## Brand assets

The app icon and installer artwork are generated by
[`scripts/branding/make-assets.ps1`](../scripts/branding/make-assets.ps1)
(Ember palette). Regenerate them after changing the brand colours:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/branding/make-assets.ps1
cd app; npx tauri icon ../scripts/branding/out/icon.png
```
